# 📝 Java To-Do List (Console Application)

A simple and beginner-friendly To-Do List application built using Java.
This project helps users manage daily tasks through a menu-driven console interface.

It is designed to practice core programming concepts like:

* Arrays
* Methods
* Loops
* Conditional Statements
* Menu-driven logic (real-world programming style)

## 🚀 Features

* ➕ Add a new task
* 📋 View all tasks
* ❌ Delete a task
* ✅ Mark task as completed
* 🔁 Menu-driven interactive system

Each task shows its status as:

* `[Pending]`
* `[Done]`

## 🧠 Concepts Used

This project is perfect for beginners learning:

* Java Basics
* Arrays and Index Management
* Boolean Logic
* User Input using Scanner
* Modular Programming (Functions/Methods)

## ▶️ How to Run the Project

### Step 1: Clone the Repository

```
git clone https://github.com/kanhaiya209/To-do-List.git
```

### Step 2: Navigate to the Folder

```
cd To-do-List
```

### Step 3: Compile the Java File

```
javac todolist.java
```

### Step 4: Run the Program

```
java todolist
```

## 📸 How It Works

1. User selects an option from the menu
2. Tasks are stored in an array
3. Boolean array tracks completion status
4. Loop keeps the program running until Exit is selected

## ⚙️ Technical Details

* Language: Java
* Type: Console Application
* Storage: In-memory (Arrays)
* Max Tasks Limit: 100
